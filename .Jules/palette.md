## 2024-09-12 - Music Player Accessibility Polish
**Learning:** Tooltips combined with native HTML attributes like `title` can cause double tooltips to render. Using `shadcn/ui` Tooltips is preferred for accessibility and consistency, but the native attributes must be explicitly removed for a polished UX. Also, nested `TooltipProvider` components aren't required as often, though wrapping multiple tooltips inside a single `TooltipProvider` provides a cleaner implementation.
**Action:** When adding custom `Tooltip` components, always ensure that conflicting native attributes (like `title`) on the trigger element are removed to avoid visual clutter and maintain a seamless user experience.
