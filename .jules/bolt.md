## YYYY-MM-DD - [Extract ChildMasteryCard]
**Learning:** Extracting list items mapped in render functions into separate React.memo components prevents unnecessary parent re-renders and allows the items to subscribe to only the state they need. Using Zustand `getState()` directly inside a React component's render function breaks reactivity and should be refactored into a `useStore` hook call with selectors.
**Action:** When finding complex map functions in JSX, extract them into separate memoized components and ensure hooks are used properly to subscribe to state, rather than using imperative `getState()` calls.
