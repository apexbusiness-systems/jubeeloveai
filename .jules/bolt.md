## 2024-05-24 - Component Rendering Optimization
**Learning:** React component optimization using `React.memo` is only effective if the parent component actually re-renders frequently or if the components receive static props that prevent them from matching the parent's re-render cycle. In static pages like `Home.tsx` and `GamesMenu.tsx`, this serves more as a defensive optimization against future state changes than addressing an immediate bottleneck. Wait for a proven bottleneck (e.g. Profiler metrics showing wasted renders on large lists) before aggressively applying memoization.
**Action:** When picking daily boosts, ensure the "bottleneck" is tangible and measurable in the application's current state, rather than a theoretical "best practice" optimization applied to rarely-updated components.
